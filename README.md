# 느금마 디펜스 — 엄마를 지켜라!

브라우저에서 실행하는 실시간 디펜스 게임 프로젝트입니다.

## 실행
- 저장소의 `index.html`을 내려받아 브라우저에서 열면 됩니다.
- GitHub Pages를 켜면 웹 주소로도 실행할 수 있습니다.

## 현재 구현
- 3행 × 5열 캐릭터 배치판
- 실시간 적 이동 및 자동 라운드 진행
- 코인 소환, 캐릭터 EXP 강화, 캐릭터 1회 이동
- 제너럴 K, 클라이벳, 미사 기본 공격과 일부 성장 스킬
- 엄마 HP, 일시정지, 재시작

## 개발 메모
현재 버전은 게임 플레이 기반을 만든 초기 버전입니다. 캐릭터 스킬의 세부 동작, 보스 및 라운드별 난이도, 적의 공격과 UI 피드백은 이후 명세에 맞춰 계속 보완합니다.
